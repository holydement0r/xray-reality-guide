# Scamalytics 分数怎么看：多少分算能用

[Scamalytics](https://scamalytics.com/) 是最常被引用的 IP 欺诈风险评分，0–100，越低越好。但它经常被误读，说清楚几件事。

## 分数在衡量什么

它衡量的是 **IP 的欺诈/滥用风险信誉**，不是"是不是住宅"。数据来自代理/VPN 检测、滥用历史、这个段的行为记录。所以：

- 一个机房 IP 只要没进滥用库、没被标代理，**也可能是低分**。
- 一个住宅 IP 如果被大量账号滥用过，**也可能是高分**。

## 实用区间（按用途）

| 分数 | 大致含义 |
|---|---|
| 0–25 | 低风险，养号/注册基本没问题 |
| 25–50 | 中等，看平台严不严 |
| 50+ | 偏高，敏感平台容易被拦 |

注意各家阈值说法不一，别把某个具体数字当铁律。

## 为什么低分照样被封

Scamalytics 只是众多信号之一。平台自己的风控还看：设备指纹、行为、注册节奏、支付方式、同 IP 关联账号数。IP 干净只是必要条件，不是充分条件。

## 验货流程

1. 查 ASN 归属（住宅还是机房）—— [IP 检测工具](https://dementor.cn/tools/ip-check/)
2. 看 Scamalytics 分
3. 交叉验证：IPQualityScore、Spur、IPinfo
4. 查 rDNS
5. 目标平台上小号实测
