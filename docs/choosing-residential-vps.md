# 美国家宽 / 住宅 IP VPS 怎么选

买家宽节点前，先分清三件互相独立的事，很多人混在一起才踩坑。

## 1. IP 归属：住宅 vs 机房

风控看 ASN 登记在谁名下。家庭运营商（AT&T / Comcast）= 住宅；云厂商 / 骨干网 = 机房。养号要住宅。详见 [家宽 IP vs 机房 IP](home-isp-vs-datacenter.html)。

## 2. 回国线路：9929 / 4837 / CN2 GIA

这是三种回国优化线路，**只影响你连它的速度**，跟 IP 干不干净是两码事。想日常当梯子用，选带优化线路的。

## 3. 双 ISP

一个 IP 同时挂两个 ISP 标识，风控里权重更高，TikTok / 养号偏好这个。

## 别只信"住宅"标签

卖家标"住宅"不一定准，自己验：查 ASN + Scamalytics 分 + rDNS。核心原则：**机房 IP 不一定高风险，住宅 IP 不一定低风险，最终看信誉分。**
